# 08. UX / Prototype

**Interactive prototype:** https://karakat177.github.io/food-coop-diploma/prototype/

FoodCoop KZ is a mobile app for group food purchases and near-expiry deals in Astana, Kazakhstan (prices in KZT). The clickable prototype covers the key user scenarios from the use case diagram.

## Scenarios
| # | Scenario | Actor | Screens |
|---|---|---|---|
| 1 | Registration | All users | Welcome → Registration (role and phone number) |
| 2 | Join a group purchase | Member | Home → Pool details → Join pool |
| 3 | Reserve a near-expiry product | Member | Home → Near-expiry deals → Reservation |
| 4 | Demand forecast and create a pool | Pool Organizer | Pools → Demand forecast → Create pool |
